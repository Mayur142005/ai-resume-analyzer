# 📄 AI Resume Analyzer

## 📌 Project Overview

AI Resume Analyzer is a Streamlit-based application that analyzes uploaded resumes and provides ATS-style feedback.

The system extracts resume text from PDF files, identifies skills, calculates an ATS score, detects missing skills, and provides suggestions for improvement.

---

## 🚀 Features

- Upload PDF resume
- Resume text extraction
- Skill detection
- ATS score calculation
- Missing skill identification
- Resume recommendations
- Download analysis report

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- PDFPlumber
- Scikit-learn
- Git & GitHub

---

## ⚙ Workflow

1. Upload Resume PDF
2. Extract Text
3. Detect Skills
4. Compare Skills
5. Calculate ATS Score
6. Generate Suggestions
7. Download Report

---

## 📈 Project Output

The application generates:

- ATS Score
- Detected Skills
- Missing Skills
- Resume Improvement Suggestions
- Downloadable Analysis Report
